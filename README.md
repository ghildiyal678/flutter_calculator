# Flutter Calculator

A simple and responsive calculator app built with Flutter and Dart.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication and division
- Percentage calculation
- Decimal calculations
- Brackets
- Backspace and clear button
- Responsive design for different screen sizes
- Modern dark purple theme
- Colorful calculator buttons

## Technologies Used

- Flutter
- Dart
- math_expressions

## Project

This project was created as a practice project to learn Flutter UI development, responsive design, and basic calculator functionality.
